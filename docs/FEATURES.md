# CNflick v2.0 功能说明

## 输入体系

- 12 键 Flick 主键盘，支持中心点按、四向滑动与八方向扩展映射。
- 拼音、注音、日语假名、ABC 英文、数字符号、五笔 86/形码输入可在同一输入法内切换。
- 地球键可配置为语言切换、隐藏或禁用，循环语言集合可单独选择。
- 英文键盘支持传统 ABC 与 MessagEase 风格映射。

## 中文候选

- 中文词库支持拼音与注音共用。
- 候选结果包含单字、词语、短句与整句。
- 选词会参与学习，常用候选会更靠前。
- 拼音首字母检索直接基于词库拼音索引生成，支持多字词首字母、分词符以及 `s/sh`、`z/zh`、`c/ch` 兼容。
- 删除回退更细粒度，误输入时减少整段重输。

## 语音与候选栏工具

- 内置离线 STT 模型，可在输入法内直接语音转文字。
- 语音输入不依赖系统语音键或系统输入法语音服务。
- 输入简单算式时，候选栏可给出本地计算结果。
- 输入“时间”时，候选栏可给出当前系统时间。

## 数字、符号与映射

- 数字键盘区支持直接输入加、减、乘、除等运算符。
- 拼音、注音、日语、英文、数字、符号映射分别管理。
- 映射支持 JSON 导入导出。
- 空格键固定在 12 宫格底部中间点按区，右侧功能区保留语音键。

## 形码与五笔

- 内置五笔 86 码表。
- 支持形码输入模式与候选查询。
- 形码词库可与其他输入模式并存。

## 主题与外观

- 支持主题色、字体、背景图、按键图、按键音效。
- 支持主题包导入与切换。
- 支持按键文字、透明度、字号、间距、按键尺寸等外观设置。
- 适配三键导航手机底部安全区域，避免键盘被系统导航遮挡。
