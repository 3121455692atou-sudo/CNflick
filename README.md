## v2.0 功能亮点

- 12 键 Flick 主键盘，支持点按、四向与八方向滑动映射。
- 拼音、注音、日语假名、ABC 英文、数字符号、五笔 86/形码输入统一管理。
- 中文候选支持词语、短句、整句与用户选择学习。
- 拼音首字母检索接入词库拼音索引，兼容 `s/sh`、`z/zh`、`c/ch` 等输入习惯。
- 本地离线语音输入，内置 SenseVoice STT 模型，不依赖系统语音键。
- 候选栏本地工具：输入算式可给出计算结果，输入“时间”可给出当前系统时间。
- 数字键盘区支持加、减、乘、除等运算符与自定义映射。
- 空格键固定进入 12 宫格底部中间点按区，右侧功能区保留语音键。
- 针对三键导航手机适配底部安全区域，避免输入法被系统导航遮挡。
- 主题系统支持主题色、字体、背景图、按键图、按键音效与主题包导入。
